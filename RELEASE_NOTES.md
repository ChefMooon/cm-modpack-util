# CM Modpack Util release notes

- Windows updater installation now downloads first and offers **Install and
  restart** or **Later** before closing the application.
- Deferring an update suppresses duplicate notifications for that release.
- Release notes are copied into the GitHub release and updater manifest at
  build time.

Update this file before creating each release tag. Editing the GitHub draft
after the workflow runs does not change the already-published manifest notes.
